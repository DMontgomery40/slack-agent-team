# Skill architecture

Compared with [Matt Pocock’s skills](https://github.com/mattpocock/skills) at [revision 49dd158d1076134a641b33efb035946536778336](https://github.com/mattpocock/skills/commit/49dd158d1076134a641b33efb035946536778336), October 17, 2026.

The package follows a short executable entrypoint with conditional reference links, checkable completion criteria, and separate reusable assets. His [writing-for-agents guidance](https://github.com/mattpocock/skills/blob/49dd158d1076134a641b33efb035946536778336/skills/productivity/writing-for-agents/SKILL.md) distinguishes ordered steps from reference and favors explicit triggers for loading additional material. His [research skill](https://github.com/mattpocock/skills/blob/49dd158d1076134a641b33efb035946536778336/skills/engineering/research/SKILL.md) illustrates a compact artifact-oriented procedure.

Here, `SKILL.md` is the sole top-level procedure. `setup-workflow.md` holds conditional inventory, provisioning and handover detail. Separate references handle interoperability, notification switches, credential ownership, shared context, pstack, and custom delivery. Grok/Cursor ambiguity triggers `grok-cursor-identity.md`; APP/AGENT or token setup triggers `slack-apps-and-agents.md`. JSON/Markdown assets are planning records and output templates. Research/review files preserve evidence without becoming mandatory context on every setup.

Pocock’s [invocation conventions](https://github.com/mattpocock/skills/blob/49dd158d1076134a641b33efb035946536778336/.agents/invocation.md) distinguish human-only and model-invoked skills. This package intentionally uses one agent-consumable entrypoint: the human points an assistant at it, and the assistant executes the applicable steps. No extra human slash-command ceremony is required. Cross-harness dependencies are read directly when native invocation is unavailable, with capability gaps recorded honestly.

The main maintenance risk is duplicating the same policy across many files. Keep source detail in its owning reference and use pointers in the entrypoint and setup sequence. Templates may illustrate a policy but cannot replace the installed runtime’s real configuration or acceptance evidence.
